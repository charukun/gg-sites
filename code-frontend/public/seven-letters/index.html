HOW IT WORKS

偶然を、少しだけ設計する。

01

7日後の日記が届く

未来のあなたが残したような短い日記。時間・行動・小さな目印が書かれています。

02

その通りに動いてみる

無理な指示はなし。散歩、カフェ、書店、公園など、日常を少しだけずらす行動です。

03

同じ未来を選んだ人が現れる

条件が重なった相手がいたら、顔写真より先に「その人の日記の一節」が届きます。

04

お互いが選んだ時だけ会話へ

双方が「続きを読んでみたい」を選んだ時だけプロフィールとチャットが開きます。

安全設計

自宅・職場・正確な現在地を相手に公開しません。深夜帯・危険地点・一対一の密室につながる指示は生成しない前提です。
